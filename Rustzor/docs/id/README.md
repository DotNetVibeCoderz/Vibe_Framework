# Dokumentasi Rustzor

[English](../en/README.md)

Rustzor menjalankan aplikasi C# Razor di browser di atas RustNetRuntime, runtime .NET yang ditulis dengan Rust dan dikompilasi ke WebAssembly.

## Mulai dari sini

1. [Memulai](getting-started.md): aplikasi yang berjalan dalam lima menit.
2. [Arsitektur](architecture.md): bagaimana build, runtime, dan browser saling terhubung.
3. [Contoh Aplikasi](samples.md): lima aplikasi lengkap, dengan screenshot.

## Menulis aplikasi

- [Component, routing, dan form](components.md)
- [Rustzor.UI](ui.md): component kit
- [Interop JavaScript](interop.md): `Js`, `JsObject`, callback, JSON, menulis library
- [API Browser](browser-apis.md): package `Rustzor.Browser.*`
- [Framework](frameworks.md): data, game, grafis, AI
- [Integrasi](integrations.md): Bootstrap, Tailwind, Material UI, ECharts, Chart.js, D3
- [Jaringan](networking.md): Fetch, WebSocket, SignalR, gRPC-Web
- [Mode build](aot.md): interpreted dan AOT

- [RustzorAppGen](appgen.md): generator aplikasi berbantuan AI
- [Build dari source](building-from-source.md): build, test, pack, rilis
