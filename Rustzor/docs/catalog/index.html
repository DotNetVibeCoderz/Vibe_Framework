Every Rustzor package, ready to install.

C# Razor apps in the browser on RustNetRuntime, a .NET runtime written in Rust and compiled to WebAssembly. 45 packages at 0.1.0-preview.1; reference only what your app uses.

Start in three commands

  1. dotnet tool install -g Rustzor.Cli --prerelease
  2. rustzor new app MyApp
  3. cd MyApp && rustzor serve
45 packages

Core 6

The SDK, the component model, the UI kit and the tools.

Rustzor.Cli

The rustzor command for Rustzor apps (C# Razor in the browser on RustNetRuntime): rustzor new, rustzor serve with live reload, rustzor publish, rustzor add, rustzor info.

dotnet tool install -g Rustzor.Cli --prerelease

Rustzor.Components

Rustzor components: a Blazor-compatible component model (ComponentBase, RenderTreeBuilder, EventCallback, @bind, routing, layouts, forms, DI) rendered by a virtual-DOM diff on RustNetRuntime in the browser. Write .razor files; no ASP.NET Core assemblies are needed.

dotnet add package Rustzor.Components --version 0.1.0-preview.1

Rustzor.Core

Rustzor core: the JavaScript bridge, callbacks, timers and a JSON reader/writer for C# running on RustNetRuntime in the browser.

dotnet add package Rustzor.Core --version 0.1.0-preview.1

Rustzor.Sdk

Rustzor SDK: build C# Razor apps that run in the browser on RustNetRuntime (Rust, compiled to WebAssembly). Use as <Project Sdk="Rustzor.Sdk/0.1.0-preview.1">. dotnet build produces a static site; -p:RustzorAot=true adds ahead-of-time WebAssembly.

<Project Sdk="Rustzor.Sdk/0.1.0-preview.1">

Rustzor.Templates

Project templates for Rustzor: C# Razor apps that run in the browser on RustNetRuntime (Rust, compiled to WebAssembly). dotnet new rustzor, rustzor-empty, rustzorlib.

dotnet new install Rustzor.Templates::0.1.0-preview.1

Rustzor.UI

Rustzor.UI: a professional component kit for Rustzor apps — app shell, data grid, SVG charts, stat cards, modals, tabs, toasts, forms and icons, themed for light and dark.

dotnet add package Rustzor.UI --version 0.1.0-preview.1
or rustzor add ui

Frameworks 4

Rustzor.AI

Rustzor.AI: AI for Rustzor apps. Streaming chat with OpenAI, Azure OpenAI, Anthropic Claude, Ollama and any OpenAI-compatible endpoint; embeddings; an in-memory vector store and a retrieval-augmented generation pipeline; and local inference in the browser with transformers.js or Chrome's built-in model.

dotnet add package Rustzor.AI --version 0.1.0-preview.1
or rustzor add ai

Rustzor.Data

Rustzor.Data: data in the browser for Rustzor. Typed IndexedDB object stores, SQLite (sql.js) with persistence, and DuckDB WASM for analytics over CSV, Parquet and JSON — all from C#.

dotnet add package Rustzor.Data --version 0.1.0-preview.1
or rustzor add data

Rustzor.Game

Rustzor.Game: a 2D game framework for Rustzor. Entity-component-system world, fixed-step game loop, keyboard/pointer/gamepad input, 2D physics with collisions, tweens, cameras, sound effects and multiplayer sessions over WebSocket or BroadcastChannel.

dotnet add package Rustzor.Game --version 0.1.0-preview.1
or rustzor add game

Rustzor.Graphics

Rustzor.Graphics: graphics for Rustzor. A retained 2D scene graph with pan/zoom, hit testing, selection, SVG and JSON export on Canvas; RGBA pixel operations for image editing; and a WebGL 3D renderer with primitives, OBJ loading, orbit camera and picking.

dotnet add package Rustzor.Graphics --version 0.1.0-preview.1
or rustzor add graphics
