# Vibe_Framework

Collection of Framework (library, tools, apps, dsb)

| Project | What | Packages |
| --- | --- | --- |
| [RustNet](RustNet) | .NET on microcontrollers, powered by a Rust runtime | `RustNet` on nuget.org |
| [Rustzor](Rustzor) | C# web apps in the browser on RustNetRuntime (Rust, compiled to WebAssembly): Razor components, a UI kit, browser APIs, frameworks, SignalR and gRPC-Web clients, an AI-assisted app generator | `Rustzor.*` on nuget.org |

Each project has its own README (English and Bahasa Indonesia) and its own CI and publish workflows in `.github/workflows` (`rustnet-*.yml`, `rustzor-*.yml`).
